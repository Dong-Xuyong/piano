# Piano

A read-only piano practice dashboard for tempo, ear training, and sight reading.

Live: https://dong-xuyong.github.io/piano/

Data lives in Dong-Xuyong/progress-sync, file piano.json.

The page auto-loads that file on open, on focus, and every 60 seconds.

Nothing on the page is editable. Grok writes the file.

CONTRACT.md is the writer spec for updating piano.json.
